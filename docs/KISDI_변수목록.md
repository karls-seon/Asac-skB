# KISDI 한국미디어패널조사 — 뽑을 변수 목록

합성 고객 데이터의 **분포 근거**로 쓸 자료. 임의로 정한 분포가 아니라 실측
분포를 따르게 하려면 이게 있어야 한다.

- 자료: 한국미디어패널조사 개인조사 (KISDI), 코드북 `P_codebook_v32.xlsx`
- 최신 조사: **2025년** (아래 핵심 변수 전부 2025년 값 있음)
- 변수명 규칙: `p__xxxxx`의 `__`에 조사연도 두 자리. 2025년이면 `p25c01002`

---

## 알아야 할 것 4가지

### 1. 이 조사에 없는 변수

**월 데이터 사용량 GB · 통화 분수 · 문자 건수 · 테더링.**
`GB|기가|트래픽|사용량`으로 전체 변수를 검색하면 3건 걸리는데 전부 무관하다
("10기가 인터넷 인지도" 등). 원자료를 받아도 안 생긴다 — 조사 문항 자체가 없다.

데이터·통화·문자는 **무제한 가입 여부만** 있다. 그래서
[입력 스키마](입력_스키마.md)에서 통화·문자를 bool로 받는다.

### 2. 코드북만으로는 변수 간 상관을 못 살린다

코드북에는 변수별 **주변분포(marginal)만** 있고 **결합분포(joint)가 없다.**
"20대이면서 알뜰폰을 쓰는 비율"은 여기 없다. 각 변수를 독립으로 뽑으면
*"70대인데 데이터 무제한 가입"* 같은 비현실적 조합이 섞인다.

→ **원자료(마이크로데이터) 신청이 필요하다.** 가능 여부 확인할 것.

### 3. 요금제명이 우리 데이터와 안 맞는다

`p25a03010`의 항목 목록에는 `SKT_3G band 데이터 6.5G` 같은 2010년대 3G
요금제까지 들어 있다(해당 시트 134,174행). 우리 크롤링 데이터는 현재 판매 중인
휴대폰 5G/LTE 요금제 2,772개뿐이다.

**이름 매칭 작업이 따로 필요하고, 매칭 안 되는 응답이 많이 나올 것**을 전제해야
한다. `current_plan_id`를 못 채우는 합성 고객이 상당수 생긴다.

### 4. 미확인 — 총액에 할부금이 포함인가

`p25c01001`(월평균 휴대폰 이용 총 금액)이 기기 할부금을 포함하는지 코드북만으론
확정할 수 없다. 할부금을 따로 묻는 문항(`p25c01003`)이 있는 걸 보면 포함일
가능성이 높다. **조사표 원문에서 확인할 것.**

할부금이 1만원 미만인 응답이 64.6%라, 빼더라도 3~5만원대는 유지된다.

## 이 자료가 드러낸 두 가지 괴리

둘 다 설계에 직접 영향을 준다.

### ① 알뜰폰 4.1% vs 우리 데이터 80%

```
실제 가입자   알뜰폰  4.1%
우리 요금제   MVNO   80.4%   (2,229 / 2,772)
```

합성 고객을 실제 분포로 만들면 96%가 통신3사 가입자인데, 추천 후보의 80%가
알뜰폰이다. **추천 대부분이 "알뜰폰으로 갈아타세요"가 된다.** 틀린 추천은
아니지만, `mvno_ok=False`인 사용자에게는 후보가 2개로 붕괴한다.

### ② 사람들이 내는 돈 vs 시장 가격

```
실제 납부액 중앙값    4~5만원 구간
우리 요금제 중앙값     18,000원   (p75 = 30,900원)
```

**2.5배 격차.** 이 서비스가 존재할 이유를 숫자 하나로 보여주는 지표다.
