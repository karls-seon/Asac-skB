# (대체됨) 페르소나 설계

이 문서의 페르소나 6종 기반 설계는 **`docs/세그먼트_설계.md`로 대체됐다.**

팀 노션에 더 정교한 설계(고객/이용량/가입정보 테이블 + 연령세그먼트 + 이용형태
세그먼트 S1~S6, 3개월 이용량 기반 적합도 판정)가 있어서, "일단 S1~S6로 진행하고
이후 필요하면 세분화하자"고 정하고 그쪽으로 옮겨갔다. 여기 있던 6종 페르소나
(자취생 헤비유저 / 가성비 알뜰폰 알뜰족 / 청년 실속형 / 청소년·키즈 보호자용 /
시니어 실속형 / 가족 결합 다회선 헤비유저)와 통계 파라미터, EDA 근거는 git
히스토리에 남아 있다.

이 과정에서 확인한 EDA 사실들(MVNO는 voice/sms 무제한 비율이 약 50%뿐, 연령
전용 요금제는 전량 MNO)은 여전히 유효하고 `docs/세그먼트_설계.md`에도 반영돼
있다.

`src/analysis/generate_synthetic_users.py`(페르소나 기반 생성기)는 삭제됐다.
지금은 `src/analysis/generate_synthetic_customers.py`를 쓴다.
