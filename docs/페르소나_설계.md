# 페르소나 설계 및 합성 유저 데이터 파라미터 근거

실제 사용자 이용패턴 데이터는 없다([[api-unavailable-crawling-decision]] 참고 — 요금제 쪽만
크롤링으로 확보했고, 통신사 가입자 데이터는 API 접근이 불가능해 애초에 존재하지 않는다).
그래서 합성 유저 데이터를 만들어 Usage Prediction/Segmentation Agent(군집화)와 Plan
Matching Agent 개발의 재료로 쓴다.

## 이 문서의 성격과 한계

여기 정의한 페르소나는 **외부 벤치마크(공공데이터 가입자 통계, Kaggle telecom-data) 없이**,
`notebooks/eda_plans.ipynb`(요금제 EDA, 셀 단위로 하나씩 확인)와 일반적인 도메인 상식만으로
잡은 **가설**이다. 군집화(K-means/GMM)로 실제 데이터 기반 세그먼트를 뽑는 건 다음 phase
몫이고, 그때 여기 페르소나와 군집 결과가 얼마나 맞아떨어지는지 검증한다. 즉 이 문서는
"정답"이 아니라 "합성 데이터를 그럴듯하게 만들기 위한 임시 가정표"다.

**통화·문자 축은 통신사 유형에 따라 신뢰도가 다르다.** 처음엔 "대부분 요금제가 무제한이라
이 축은 근거가 약하다"고 가정했는데, 노트북에서 `voice_unlimited`/`sms_unlimited`를
`carrier_type`별로 나눠 보니 그렇지 않았다: **MNO는 94~95%가 무제한이지만 MVNO는 약
50~52%만 무제한**이다. 즉 MVNO 지향 페르소나에게는 통화·문자량이 실제로 요금제 선택을 가르는
변수다. MNO 지향 페르소나에서는 여전히 근거가 약하다는 원래 가정이 맞다.

**통신사 선호(carrier_type 선호)는 데이터로 완전히 추론할 수는 없지만, 일부는 데이터가
못을 박는다.** 연령 조건(`age_condition`)과 `carrier_type`을 교차해보니, **연령 전용
요금제(청년 덤·시니어 특화 등)는 노트북에서 확인된 범위 내에서 전량 MNO였고 MVNO는
0건**이었다. 즉 알뜰폰 쪽에는 "청년 할인", "시니어 특화" 같은 조건부 상품 자체가 없다.
그래서 연령 조건에 기대는 페르소나(③④⑤)는 MNO 선호 비율을 데이터가 뒷받침하는 만큼
올렸다. 그 외의 선호(브랜드 충성도 등)는 여전히 순수 가정이다.

## 요금제 EDA에서 가져온 근거 수치

`notebooks/eda_plans.ipynb` 실행 결과(2026-08-03) 기준.

| 지표 | MNO(통신 3사) | MVNO(알뜰폰) |
|---|---|---|
| `discounted_fee` 중앙값 | 67,500원 (25%=37,500 / 75%=82,500 / max=97,500) | 14,500원 (25%=6,900 / 75%=23,000 / max=65,890) |
| 데이터 무제한 비율 | 59.5% | 0.0% |
| 정량 요금제 `data_gb` 중앙값 | 15GB (25%=6 / 75%=50) | 11GB (25%=7 / 75%=17) |
| `voice_unlimited` 비율 | 94.9% | 52.1% |
| `sms_unlimited` 비율 | 93.5% | 50.4% |

음성이 무제한이 아닌 요금제만 보면 제공 분수는 중앙값 200분(25%=100 / 75%=300)이다. 다만
최댓값 9,997분은 육안으로 봐도 이상치라 참고만 하고 페르소나 파라미터 근거로는 안 썼다.

연령 조건: 전체의 89.5%는 연령 무관 일반 요금제. 연령 전용은 `만 34세 이하`(98행, 청년) >
`만 65세 이상`(60행, 시니어) > `만 18세 이하`(58행, 청소년) > `만 75세 이상`(49행) >
`만 12세 이하`(14행, 키즈) 순이며, **이 조건들은 모두 MNO(KT/SKT/LGU+) 요금제에서만
나타났다** — MVNO 교차표는 전 구간에서 0건.

알뜰폰 브랜드는 상위 몇 개(티플러스 221 / 프리티 181 / 스마텔 173 / 아이즈모바일 170)에
쏠려 있긴 하지만 15개 브랜드가 고르게 60건 이상씩은 가지고 있어, 특정 브랜드 하나가
시장을 지배하는 구조는 아니다(페르소나에 브랜드까지는 반영하지 않음 - 범위 밖).

## 페르소나 6종

| 페르소나 | 연령대 | 데이터 사용량(GB) | 통화(분) | 문자(건) | 월 예산(원) | 통신사 선호(MNO:MVNO) |
|---|---|---|---|---|---|---|
| ① 자취생 헤비유저 | 20~29 (μ24,σ3) | μ80 σ40, 30GB↑ (사실상 무제한 지향) | μ150 σ80 | μ20 σ15 | μ75,000 σ12,000 | 85:15 |
| ② 가성비 알뜰폰 알뜰족 | 25~55 (μ38,σ10) | μ6 σ3 | μ100 σ60 | μ10 σ8 | μ9,000 σ3,000 | 5:95 |
| ③ 청년 실속형 | 19~34 (μ27,σ5) | μ20 σ10 | μ180 σ90 | μ20 σ15 | μ25,000 σ8,000 | **70:30** |
| ④ 청소년/키즈 보호자용 | 8~18 (μ14,σ3) | μ4 σ2 | μ60 σ40 | μ30 σ20 | μ12,000 σ4,000 | **75:25** |
| ⑤ 시니어 실속형 | 65~85 (μ72,σ6) | μ3 σ2 | μ200 σ100 | μ15 σ10 | μ15,000 σ6,000 | **70:30** |
| ⑥ 가족 결합 다회선 헤비유저 | 35~55 (μ44,σ6) | μ100 σ40 (무제한+공유 니즈) | μ250 σ100 | μ15 σ10 | μ88,000 σ8,000 | 90:10 |

(굵게 표시한 ③④⑤의 통신사 선호 비율은 위 "연령 전용 요금제는 전량 MNO" 발견을 반영해
이전 초안(50:50 / 60:40 / 55:45)보다 MNO 쪽으로 올린 값이다.)

- 데이터·예산 μ/σ는 위 EDA 표의 사분위수 구간에 각 페르소나를 대응시켜 잡았다(예: ②는
  MVNO 25%=6,900원/7GB 구간, ⑥은 MNO 75~max 구간).
- 각 필드는 정규분포로 샘플링 후 하한(0 또는 최소 의미값)에서 클리핑한다. 나이는 페르소나
  구간 내 균등분포.
- 페르소나별 표본 수: 120명 (총 720명). 부트캠프 프로토타입 규모로 충분하고, 6개 페르소나가
  뭉개지지 않을 만큼(페르소나당 최소 100+)은 되는 절충점.

## 다음 단계와의 연결

`src/analysis/generate_synthetic_users.py`가 위 표의 파라미터를 코드 상수로 그대로 옮겨
`data/synthetic/synthetic_users.csv`를 생성한다. 이후 Usage Prediction/Segmentation
Agent(다음 phase)가 이 합성 데이터에 K-means/GMM을 돌려 **데이터 기반 세그먼트**를 뽑고,
그 결과를 여기 6개 페르소나와 대조해 페르소나 정의를 다듬는다. Plan Matching Agent를 만들
때는 MVNO 지향 유저(페르소나 ②)의 경우 `voice_unlimited`/`sms_unlimited`가 절반만 True라는
점을 실제로 필터링 로직에 반영해야 한다(무제한이라고 가정하면 안 됨).
