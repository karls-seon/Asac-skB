# 요구사항 정의서 & 서비스 기획서

/ 타겟 사용자 · 핵심 기능 · 유즈케이스 · 화면설계

---

## 1. 왜 만드는가

요금제는 2,797개다. 이 중 어느 하나를 고르는 일이 사람에게 너무 어렵다는 게
전제였는데, 실제로 얼마나 손해가 나는지 재봤다.

모요 알뜰폰 2,224개를 전수 대조했다. 기준은 **데이터가 같거나 많고, 통화가 같거나
많으면서, 더 싼 요금제가 있는가.**

| 지표 | 값 |
|---|---|
| 동급 이상이면서 더 싼 대안이 있는 요금제 | **99.2%** |
| 가입자 가중 월 평균 초과 지출 | **8,113원** |
| 절감액 중앙값 (상품 기준) | 13,200원 |

가입자 수(316만 건 실측)로 가중해도 월 8,113원이 샌다. **사람들이 실제로 고른
요금제는 최적이 아니다.** 이 숫자가 이 서비스의 존재 이유이자 성과 지표다.

> 혜택·프로모션 기간을 무시한 계산이라 **상한선**으로 읽어야 한다.

## 2. 타겟 사용자

**요금제를 직접 비교해 보려는 사람.** 통신사 대리점에 맡기지 않고 스스로 고르려는
쪽이다.

주 시나리오는 **통신3사 → 알뜰폰 갈아타기**다. 통신3사끼리 옮기는 경우는
대부분 요금제를 바꾸려는 게 아니라 **휴대폰을 바꿀 때** 딸려오는 것이라
우선순위에서 뺐다. 기기 할부·공시지원금·선택약정 같은 MNO 전용 분기를 만들지
않은 이유다.

**대상이 아닌 것**

| 뺀 것 | 이유 |
|---|---|
| 기기 구매 상담 | 요금제 문제가 아니다 |
| 인터넷·TV 결합 | 크롤링 범위 밖이라 요금제 41개 컬럼에 결합 정보가 없다 |
| 가족 결합 할인 | 위와 같다 |

## 3. 핵심 기능

| # | 기능 | 설명 |
|---|---|---|
| F1 | 조건 입력 | 필수는 **예산·데이터 둘뿐**. 나머지 6개는 비우면 통과 |
| F2 | 사용량 모름 대응 | GB를 모르면 **습관 4개**로 되묻는다 |
| F3 | 자유입력 | 문장으로 말해도 슬롯으로 옮긴다. 부족하면 되묻는다 |
| F4 | 추천 5개 | 조건 필터 → 점수 → 정렬 → 중복 제거 |
| F5 | 가성비 표시 | 스펙 대비 시세보다 얼마 싼지 |
| F6 | 절감액 | 지금 내는 요금을 알려주면 월 얼마 아끼는지 |
| F7 | **0건 완화** | 조건에 맞는 게 없으면 풀어서 다시 찾고 **무엇을 풀었는지 말한다** |
| F8 | 추천 근거 설명 | 왜 이걸 골랐는지 문단으로 |
| F9 | OTT 안내 | 원하는 OTT가 예산 안에 없으면 최저가를 알려준다 |

### 안 넣은 것과 근거

| 뺀 것 | 근거 |
|---|---|
| 통화 분수·문자 건수 입력 | `voice_minutes` 결측 61.8%, `sms_count` 60.5%. 그 값으로 거르면 스펙이 나빠서가 아니라 **사이트가 값을 안 적어서** 탈락한다. 무제한 여부는 결측 0% |
| 테더링 조건 | `tethering_support`에 `supported` 값 자체가 없고 4종(미지원/별도한도/데이터차감/미공시)이라 기준이 안 선다 |
| OTT를 기본 필터로 | 예산 3만원 이하 2,014개 중 OTT가 붙은 건 221개. 항상 걸면 후보의 **89%**가 날아간다. 사용자가 켤 때만 필터가 된다 |
| 멤버십 등급 입력 | 사용자가 먼저 요구하는 값이 아니라 비싼 요금제에 딸려오는 결과 |

## 4. 유즈케이스

### UC-1 갈아타기 (주 시나리오)

```
지금 월 69,000원 · 예산 30,000원 · 데이터 20~50GB · 통화 무제한
  → 핀다이렉트Z 100GB+   6,900원   월 62,100원 절약
```

### UC-2 사용량을 모름

```
사용자: 데이터 얼마나 쓰는지 모르겠어 3만원 정도
시스템: 그러면 평소 습관으로 가늠해 볼게요. 어느 쪽에 가까우세요?
        집·회사 와이파이만 / 가끔 영상 / 매일 영상 / 밖에서도 계속
```

### UC-3 조건을 못 맞춤 (전체 입력 조합의 15%)

```
예산 5,000원 · 통신3사만 · 통화·문자 무제한
  → 푼 조건: 문자 무제한 → 통화 무제한 → 알뜰폰 제외
  → "요청하신 조건으로는 결과가 없어 … 조건을 뺐습니다"

예산 1,000원 · 100GB · 통신3사만
  → "예산을 월 7,000원까지 올리면 추천할 수 있습니다"
```

**예산과 데이터는 절대 풀지 않는다.** 몰래 풀면 못 내는 돈을 추천하게 된다.

### UC-4 OTT를 원함

```
"넷플릭스 있으면 좋겠고 3만원대 50gb"
  → 추천 5개 + "예산 39,000원 안에는 '넷플릭스' 포함 요금제가 없습니다.
                가장 싼 것은 66,750원(베스트 89(넷플릭스))입니다."
  → "넷플릭스 있는 것만 보기"를 켜면 6만원대 목록으로 바뀐다
```

가격이 10배 차이 나는 걸 **보고 나서** 사용자가 켠다. 넷플릭스를 원한다고
6,060원짜리 대신 66,750원짜리를 자동으로 밀지 않는다.

### UC-5 연령 전용 요금제

```
만 68세 → '만 65세 이상' 전용 요금제가 후보에 포함
만 27세 → 같은 요금제가 제외됨
```

나이를 안 알려주면 조건이 붙은 요금제도 일단 통과시키고 결과에 조건을 표시한다.

### 화면 규칙

- **되물음은 추천을 대신한다.** 필수가 덜 찼으면 결과 목록 대신 질문 하나만 보여준다.
- **조건을 풀었으면 반드시 배너로 알린다.** 조용히 다른 걸 추천하지 않는다.
- **프로모션 잔여 기간을 카드에 적는다.** 상위 추천이 대개 프로모션가라, 안 적으면
  나중에 오르는 걸 모른다.
- **시세 대비 가격을 같이 보여준다.** 가격만으로는 싼지 판단이 안 된다.

## 6. 비기능 요구

| 항목 | 목표 | 현재 |
|---|---|---|
| 추천 응답 | 즉시 | **5.8ms** (LLM 설명 제외) |
| 준비 시간 | 앱 기동 1회 | 4.3초 (요금제 적재 + 회귀 학습) |
| 데이터 신선도 | 매일 | `refresh_plans.py` 일 1회 |
| LLM 장애 시 | 서비스 유지 | 슬롯 추출·설명만 빠지고 추천은 그대로 |
| 조건 위반 | 0 | 무작위 400조합 위반 0건 |

## 7. 이 문서에서 다루지 않은 것

- **추천 품질**은 정답이 없어 측정하지 않는다. 대신 *조건을 지키는가*를 잰다
  (`docs/에이전트_설계.md`, `segment_ml_check.ipynb`).
- **결합상품**은 데이터가 없어 못 받는다. 원문 목표 문장에는 있으나 크롤링 범위 밖이다.
